🍣 Pure CSS Ingredient Stacker

나만의 커스텀 스시 & 보울 만들기

상단에서 원하는 재료의 체크박스를 클릭하면, 페이지 하단 트레이에 선택한 재료의 이미지가 실시간으로 쌓입니다.
(자바스크립트 없이 순수 CSS (:has / :checked)로만 동작합니다)

🍽️

1. Plating (그릇 / 접시)

스시와 보울을 담을 기본 플레이팅 용기를 선택하세요.

🍚

2. Base (밥 베이스)

취향에 맞는 스시 밥 베이스를 선택하세요.

🐟

3. Salmon (연어 메인)

신선한 프리미엄 연어 스타일을 선택하세요.

🥑

4. Toppings (신선한 토핑)

스시의 맛과 색감을 더해줄 토핑을 마음껏 선택하세요.

🍱 선택된 재료 쌓기 트레이 (Selected Ingredients)

상단에서 체크박스를 클릭한 재료들의 이미지가 아래에 실시간으로 차곡차곡 쌓입니다.

👆

아직 선택된 재료가 없습니다.
위의 카테고리에서 원하는 체크박스를 클릭해 보세요!
